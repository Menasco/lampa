# Kas plugin 2.0 — плагин для Lampa

Filmix, Zetflix, Rutube, VK Видео, AniLiberty и штатный поиск торрентов. Свой сервер для онлайн-источников не нужен.

## Что изменилось

Раньше все источники зависели от `akter-black.com`. Сообщение про `@abcinema_bot` возвращал этот сервер, а плагин переключался по кругу между недоступными источниками.

Теперь основной публичный бэкенд — **WTCH**. AniLiberty подключена отдельно через официальный API. В меню больше нет десятков посторонних балансеров; ошибки оставляют кнопки **«Повторить»** и **«Изменить балансер»**. Отправка истории запусков в трекер AKTER удалена.

| Источник | Как подключён |
|---|---|
| Filmix | WTCH, маршрут `/lite/fxapi`; первый источник при новом выборе |
| Zetflix | WTCH, `/lite/zetflix` |
| ZetflixDB | Дополнительный вариант Zetflix через WTCH |
| Rutube | WTCH, `/lite/rutubemovie` |
| VK Видео | WTCH, `/lite/vkmovie` |
| AniLiberty / AniLibria | Напрямую: `https://aniliberty.top/api/v1/` |
| Торренты | Штатный экран Lampa с уже настроенными парсером и TorrServer |

Меню показывает доступные подключения, **не гарантированное наличие конкретного фильма**. Источник проверяется при открытии. Видеоссылки, качество и доступность зависят от провайдера; отдельные фильмы и серии могут не открываться.

## Установка и обновление

После публикации этой версии в GitHub Pages адрес остаётся прежним:

```text
https://menasco.github.io/lampa/kas_plugin.js
```

Lampa → Настройки → Расширения → добавить этот URL. Если расширение уже установлено, достаточно обновить его и полностью перезапустить Lampa. Не добавляйте вторую копию. На кнопке должен появиться номер **v2.0.0**.

Первый запуск версии 2 автоматически заменяет прежний адрес `akter-black.com` на WTCH. Пользовательский адрес другого сервера сохраняется. Предыдущий адрес хранится в `ou_backend_previous`; при необходимости его можно вручную вернуть в **Настройки → Kas plugin → Бэкенд источников**. Миграция выполняется один раз.

Существующие отметки и таймлайны просмотра сохраняются. Выбор балансера теперь отдельный для Kas, а статистика запусков разделена по бэкендам: сбои старого сервера не понижают источники нового.

## Использование

1. Откройте фильм или сериал → **Kas plugin**.
2. Выберите нужный источник сверху. Озвучки, сезоны и серии остаются в привычном интерфейсе; качество выбирается в плеере.
3. В **AniLiberty** сначала выберите релиз, затем серию. Если поиск пустой, попробуйте оригинальное название через поиск сверху. Номера серий берутся из AniLiberty; таймлайны разных релизов не смешиваются.
4. **Торренты** открывают обычный поиск Lampa и не меняют выбранный онлайн-источник. Этот пункт использует вашу существующую настройку торрентов, не предоставляет новый TorrServer.

## Совместимость и ограничения

- У проверенного WTCH доступен **HTTP**, а HTTPS на том же домене при проверке не отвечал. Обычная браузерная Lampa, открытая по HTTPS, может блокировать обращения к нему как mixed content. Для неё нужен доступный HTTPS-бэкенд в настройках либо запуск Lampa по HTTP. В ТВ-приложениях результат зависит от платформы и сетевого транспорта; на самом телевизоре эта версия пока не проверена.
- AniLiberty использует HTTPS и не обращается к WTCH, в том числе за идентификаторами. Её поиск и серии доступны независимо от состояния бэкенда.
- WTCH — сторонний публичный сервис. На момент проверки перечисленные маршруты не требовали Telegram-авторизации; условия и доступность сервиса могут измениться. Это не полностью автономный плагин.
- Прямой адаптер Zetflix в актуальном Lampac использует браузер на сервере. Обычный запрос к плееру при проверке возвращал защитную страницу, поэтому для Zetflix сохранён публичный бэкенд.
- Плагин не снимает ограничения источников, не изменяет параметры рекламы в ссылках AniLiberty и не гарантирует платные уровни качества Filmix.

## Проверки

Локальные регрессионные тесты, без зависимостей, Node.js 18+:

```sh
node --check kas_plugin.js
node --test tests/plugin.test.cjs
```

Сетевые проверки **5 сентября 2026**, из текущей сети, без аккаунта AKTER/WTCH:

| Проверка | Результат |
|---|---|
| WTCH: запрос Filmix с `rchtype=cors` и `Origin: null` для Tizen | HTTP 200, варианты видео, разрешён CORS для `null`; физический телевизор не проверялся |
| WTCH: список источников | Filmix, Zetflix, ZetflixDB, Rutube и VK присутствуют |
| Filmix: «Интерстеллар» | Получен фрагмент MP4, HTTP 206 |
| Filmix: первая ссылка «Матрицы» | HTTP 404 — отдельная ссылка не работает |
| Zetflix: «Матрица» | Получен HLS-плейлист, HTTP 200 |
| Zetflix: «Во все тяжкие» | Список сезонов получен; проверенный переход к сезону вернул HTTP 502 |
| Rutube / VK: «Матрица» | Получены варианты, без требования авторизации; воспроизведение не проверялось |
| AniLiberty: поиск Naruto и релиз 413 | Поиск и серии получены; HLS-плейлист HTTP 200; API разрешил CORS для `https://lampa.mx` |

Получение плейлиста или фрагмента файла не заменяет проверку полного воспроизведения на ТВ. Подписанные видеоссылки и гостевые токены не сохраняются в репозитории.

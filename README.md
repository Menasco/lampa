# Online Ultra — плагин для Lampa

Умный фронт над проверенным движком онлайн-балансеров. Сделан так, чтобы **не показывать нерабочие источники** и не заставлять перебирать 5 вкладок с «видео не найдено».

## Установка

1. Lampa → **Настройки** → **Расширения** (или **Плагины**).
2. Добавить URL:

```
https://menasco.github.io/lampa/online_ultra.js
```

3. Открыть любой фильм/сериал → на карточке появится жёлтая кнопка **«Online Ultra»**.

Плагин при первом запуске сам подтягивает движок `online_mod` (21 балансер, авто-обновляется) — отдельно ставить ничего не нужно.

## Как это работает

- **Фильмы** играются напрямую через источник **Collaps**: плагин достаёт настоящий `.m3u8`, все озвучки уже внутри потока и переключаются в плеере кнопкой «Аудио». Это проверено рабочий путь.
- **Сериалы** и **«все источники»** открываются в движке `online_mod` — он корректно подбирает поток по каждой серии, даёт выбор сезона/серии/озвучки и сам обновляется под изменения балансеров.
- **Фильтрация:** если Collaps ничего не нашёл по фильму — вкладка-источник не показывается, вместо неё сразу предлагается полный движок. Никаких «мёртвых» кнопок.

## Настройки (Настройки → Online Ultra)

| Параметр | Зачем |
|---|---|
| **Прокси для источников** | За границей без VPN: если прямой доступ не открывает — переключите на прокси. По умолчанию «прямой + авто-фолбэк». |
| **Движок 21 балансера** | Автозагрузка `online_mod`. Оставьте включённым. |
| **URL движка** | Можно указать своё зеркало `online_mod`. |
| **Токен Collaps** | Если быстрый источник перестал искать — обновите токен. |

## Честно про «полностью рабочий»

Балансеры (Collaps, Rezka, Kodik, Filmix и т.д.) — это внешние пиратские агрегаторы. Они **периодически ломаются, меняют домены и токены, блокируются по региону** — это не зависит от плагина. Ни один плагин не может гарантировать 100 % рабочих ссылок всегда.

Что этот плагин реально делает против «то работает, то нет»:

- прячет источник, который не нашёл конкретный тайтл (не показывает битые кнопки);
- фильмы отдаёт напрямую, без прослоек-плееров, которые чаще всего и падают;
- всё, что сложнее, отдаёт постоянно обновляемому движку, а не захардкоженным ссылкам, которые быстро протухают.

## Лицензия / дисклеймер

Плагин не хостит и не раздаёт контент — он лишь агрегирует публично доступные балансеры. Используйте в соответствии с законодательством вашей страны.

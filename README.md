# Kas plugin — плагин для Lampa

Lampac-клиент: источники берутся с **сервера-агрегатора (бэкенда)**, который сам обходит 20+ балансеров (Rezka, Kodik, Filmix, Alloha, Collaps, KinoPub, HDVB, VK, Rutube, Zetflix, Phantom и др.) и возвращает только то, где фильм реально есть.

## Установка

1. Lampa → **Настройки** → **Расширения** (или **Плагины**).
2. Добавить URL:

```
https://menasco.github.io/lampa/kas_plugin.js
```

3. Открыть фильм/сериал → кнопка **«Kas plugin»** на карточке → откроется список источников.

## Почему теперь много источников и HDRezka работает

Раньше плагин пытался сам, из браузера/приставки, лезть в балансеры — их мало кто отдаёт напрямую, HDRezka требует авторизацию, домены/токены протухают. Теперь всё это делает **сервер Lampac**:

- **Много источников.** Сервер опрашивает 20+ балансеров и отдаёт готовый список — в тестах 24–27 источников на тайтл.
- **Только рабочие.** В списке появляются только те, где сервер нашёл этот фильм. Не нужно перебирать мёртвые вкладки.
- **HDRezka без «требуется авторизация».** Rezka открывается на сервере (российский IP, авторизация/зеркало — на его стороне).
- **Выбор озвучки / сезона / серии** — как отдаёт балансер, единым удобным списком.

## Как пользоваться

Интерфейс — **официальный фронтенд Lampac** (ровно как у BwaRC/online_mod):

1. Кнопка воспроизведения на карточке → сайдбар **«Источник»** → **Kas plugin**.
2. Открывается стандартный экран онлайна: сверху — фильтр **«Источник»** (балансер) и **«Фильтр»**, список серий/файлов с постерами и историей просмотра.
3. Справа выбирается **озвучка** или другой источник; качество — в самом плеере.

## Пометки источников в меню «Источник»

Плагин замеряет всё по факту — на твоём устройстве, а не по словам сервера. Успех
засчитывается **только когда видео реально пошло** (плеер начал двигать таймлайн);
битое видео с длительностью 00:00 успехом не считается — источнику записывается сбой.

- **⚡ ~Nс** (зелёный) — видео у тебя реально запускалось, от клика до старта ~N секунд.
- **🐢 ~Nс** (жёлтый) — запускалось, но медленно.
- **✕ не открылся у тебя** (красный) — ссылка не получена **или** видео так и не пошло (00:00); уезжает в конец списка.
- **· бывало сбой** — источник работал, но случались и неудачи.
- **○ потоки есть** (серый) — сервер нашёл потоки, но ты ещё не пробовал (слабый сигнал).
- **● проверяется…** — идёт живая проверка сервера.

Метки накапливаются по мере использования; быстрые источники всплывают наверх, нерабочие — вниз.

## Настройки (Настройки → Kas plugin)

| Параметр | Зачем |
|---|---|
| **Бэкенд источников (Lampac)** | Сервер-агрегатор. По умолчанию `https://akter-black.com/`. Можно указать любой другой Lampac-бэкенд или свой. |

## Свой бэкенд (максимальная независимость)

По умолчанию используется публичный бэкенд akter-black. Если хочется ни от кого не зависеть и гарантированно получать HDRezka и все источники — поднимается свой **Lampac** на VPS в РФ, и его адрес вписывается в настройку «Бэкенд». Тогда список источников и потоки идут через ваш сервер.

## Честно про ограничения

- Плагин зависит от доступности выбранного бэкенда. Публичные бэкенды иногда перегружены/недоступны — тогда меняется адрес в настройках или поднимается свой.
- Отдельные источники (например Torrent) требуют настроенного TorrServer; остальные играют напрямую.
- Плагин не хостит контент — он лишь клиент к серверу-агрегатору публичных балансеров. Используйте в соответствии с законодательством вашей страны.

# Kas plugin 2.2.1 для Lampa

Онлайн-источники Filmix, Phantom, VideoHUB, Kodik, VeoVeo, Collaps, Kinotochka, Rutube, VK Видео, AniLiberty / AniLibria.

Источники показываются после проверки каталога открытой карточки. Пустые ответы, ошибки сервера и неподходящие результаты поиска скрываются. Проверка каталога подтверждает наличие видеоссылок, но не гарантирует доступность каждого потока на любом устройстве.

## Установка и обновление

В Lampa → Настройки → Расширения добавьте:

```text
https://menasco.github.io/lampa/kas_plugin.js
```

Если плагин уже установлен, обновите расширение и полностью перезапустите Lampa. Вторую копию добавлять не нужно. На кнопке должна быть версия **v2.2.1**.

Прежний стандартный адрес WTCH один раз заменяется на публичный API Lumio. При этом Filmix, Kodik и Rutube используют WTCH. Пользовательский адрес другого сервера сохраняется. Предыдущий адрес записывается в `ou_backend_previous`; изменить сервер можно в **Настройки → Kas plugin → Бэкенд источников**, затем перезапустить Lampa.

## Изменения 2.2.1

- **Collaps** получает плеер через отдельную сессию BWA. Lampa запрашивает публичный адрес плеера для ID открытой карточки и передаёт ответ серверу BWA. При недоступной сессии используется резервный сервер BWA. Для сериалов проверка начинается с первой серии первого сезона. Источник появляется, когда сервер возвращает потоки. В Lampa на Chrome проверен запуск «Матрицы» в русском дубляже.
- **Источник** доступен сверху и в боковом фильтре по стрелке вправо. Убраны сброс фильтра, ручное обновление и поиск торрентов из бокового меню. При повторном входе плагин заново проверяет источники.
- **Kas plugin** стоит первым в списке «Смотреть» и отмечен цветной иконкой.

## Изменения 2.2.0: источники для карточки и полные сезоны Kodik

- Перед открытием списка проверяются каталоги источников: до трёх источников одновременно, общий предел 25 секунд. Для папок сезонов проверяется наличие серий, результаты поиска сопоставляются с названием и годом карточки. Ошибки и неподходящие фильмы не считаются наличием видео.
- Результат сохраняется в памяти на две минуты для этой карточки, запроса и набора серверов. Переключение источника не запускает полный поиск заново. **Фильтр → Обновить доступные источники** повторяет проверку; в пустом результате есть кнопка **Повторить**. Выход отменяет запросы.
- Убраны метки скорости, сбоев, сортировка по статистике и фоновый сбор этой статистики. Торренты доступны отдельно через **Фильтр → Поиск торрентов**.
- Kodik дополнительно ищет явно обозначенные части аниме (`ТВ-N, часть M`) по названию. Части объединяются в сезон, локальные номера продолжения переводятся в общую нумерацию, исходные ссылки остаются неизменными. Выбор озвучки содержит переводы, общие для всех частей; ошибку одной из частей нельзя принять за полный сезон.
- Названия сериалов нормализуются до создания интерфейса Explorer: его заглушка «Фильм не найден» больше не заменяет название в поиске. TMDB используется для описаний существующих видеосерий, отсутствующие у источника серии больше не дорисовываются.
- Kinotochka остаётся отдельным источником. Добавлен адаптер JSON-ответов Collaps/BWA для фильмов, озвучек, сезонов и получения ссылок следующих серий. Личные параметры аккаунта Lampac в BWA не передаются. Собственный Lampac может отдавать Collaps в обычном HTML-формате.

Проверки **22 ноября 2026 года** в настоящей Lampa через `file://` в Chrome:

- «Реинкарнация безработного», **сезон 2, AniLibria.TV**: получены ссылки на серии **0–24**; запущена серия **24**, более 80 декодированных кадров, `readyState=4`, без ошибок видео и JavaScript.
- **Kinotochka**, «Матрица»: видео воспроизводится, более 80 кадров, `readyState=4`.
- **Zetflix**, «Матрица», «DUB | Мосфильм»: после прежних отказов сервер снова отдаёт видео; воспроизведение проверено, более 80 кадров, `readyState=4`.
- На «Матрице» отобраны Filmix, Phantom, Zetflix, VideoHUB, VeoVeo, Kinotochka, Rutube и VK Видео; на проверенном аниме — Filmix, Phantom, Zetflix, Kodik, VeoVeo и Kinotochka. Это результаты конкретной проверки, доступность меняется.
- **54 автоматических теста**: отмена и ограничение времени проверки, кэш и повторный поиск, пустые каталоги, объединение частей, нормализация названий, адаптер Collaps и прежние проверки плеера/Tizen. Физический телевизор Tizen не подключён; аппаратное воспроизведение на нём не проверялось.

Использованы протоколы из [BWA](http://bwa.ad/rc), [Lumio](https://beta.mitsu.tv/plugins/lumio.js) и [открытого сервера Lampac/Kodik](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlineAnime/Kodik/Service.cs). Код плагина не подключает сторонние плагины целиком и не копирует их API-токены.

## Изменения 2.1.3: Kodik и VeoVeo

- **Kodik** добавлен в стандартный список через `/lite/kodik` на WTCH: озвучки, сезоны, серии и выбор качества. На проверенном фильме доступны 720p, 480p, 360p и 240p. Через Lumio список озвучек возвращался, но получение видеоссылок завершалось HTTP 503, поэтому для стандартного подключения выбран WTCH.
- **VeoVeo** добавлен через `/lite/veoveo` на Lumio. При повторной проверке 31.10.2026 основной и вложенный плейлисты, а также видеосегмент доступны; прежний HTTP 401 не повторился. Варианты аудиодорожек доступны в самом плеере, если их поддерживает выбранный плеер устройства.
- Оба источника доступны в поиске. Kodik также включён в список источников собственного Lampac и синхронизацию сохранённого выбора. Адрес собственного сервера и выбранный плеер сохраняются.
- Проходят **44 локальных теста**, включая разбор сезонов/озвучек Kodik, сохранение сезонов VeoVeo и передачу серий в ветке Tizen.

Сетевые проверки **31 октября 2026 года**: Kodik — «Унесённые призраками», «Невафильм», 720p; VeoVeo — «Матрица». В обоих случаях получены плейлисты и 1024 байта видеосегмента (HTTP 206). В настоящей Lampa через `file://` в Chrome оба фильма воспроизводились более 4 секунд, `readyState=4`, без ошибок видео, JavaScript и CORS. Это проверка в браузере; физический Samsung Tizen не подключён.

Также запущены первые серии «Тетради смерти» в Kodik и «Во все тяжкие» в VeoVeo. Для Kodik проверено декодирование кадров после автоматического пропуска заставки, чтобы скачок таймкода не считался успешным воспроизведением. В обоих случаях видео работает с `readyState=4`, без ошибок плеера и JavaScript.

## Исправления 2.1.2: Phantom на Samsung Tizen

- Для проверенного потока Phantom с `EXT-X-MAP` / фрагментами MP4 на Tizen используется отдельный HTML5/HLS-адаптер через API Lampa. Он включается при наличии поддержки MSE и hls.js; настройка общего плеера сохраняется. Другие источники продолжают работать через выбранный плеер.
- При наличии вариантов до 1080p Phantom на Tizen выбирает их, исключая 1440p/2160p из этого запуска. Это учитывает ограничения MSE старых Samsung, например [моделей 2017 года](https://developer.samsung.com/smarttv/develop/specifications/media-specifications/2017-tv-video-specifications.html). Выбранное пользователем качество до 1080p сохраняется.
- Следующая серия на Tizen получает ссылку, качество и проверку плейлиста через тот же путь, что и первая. Раньше она могла идти напрямую через непроверенный адрес перенаправления.
- Ошибки HLS и отсутствие старта в течение 45 секунд выводятся с кодом `Phantom (Tizen)`. Закрытие плеера освобождает HLS и отменяет таймер. Ошибка непосредственного вызова плеера также показывается пользователю.
- Источники снова называются **Filmix** и **Rutube**, без `WTCH` в названии.

Проверены 40 локальных тестов. В настоящей Lampa, запущенной в Chrome через `file://`, принудительно включена ветка Tizen и подставлен тестовый AVPlay. Новый адаптер воспроизвёл «Матрицу» в дубляже: 14,18 секунды, `readyState=4`, без ошибок JavaScript и видео; вызовов AVPlay не было. Дополнительно проверены перемотка на 30 секунд, продолжение воспроизведения, закрытие и повторное открытие озвучки «Гоблин» с движением видео более 5 секунд. Активных экземпляров HLS после закрытия — 0, настройка `player=tizen` сохранена.

**Физический Samsung не подключён.** Эти проверки подтверждают выполнение нового пути и декодирование в Chrome, но не аппаратную совместимость конкретного телевизора. По [спецификации Samsung](https://developer.samsung.com/smarttv/develop/specifications/general-specifications.html) поддержка HLS/fMP4 зависит от версии Tizen. Точная причина исходного отказа на устройстве пользователя пока не подтверждена; версия 2.1.2 добавляет альтернативный транспорт и видимые ошибки для следующей проверки на ТВ.

## Исправления 2.1.1

- Исправлено падение настроек с `Cannot read property 'https://beta.mitsu.tv/api/' of undefined`: текстовое поле адреса теперь зарегистрировано с обязательным строковым `values`. Проверено открытие настроек на сборке `https://yumata.github.io/lampa/`, указанной в сообщении с ТВ.
- Исправлен выбор резервного качества Phantom: после неудачного 1080p проверяются 720p и 480p. Раньше ограниченный список попыток мог занять 2160p/1440p, так и не проверив меньшие разрешения.
- 33 регрессионных теста проходят, включая отображение адреса в настройках и резервное 720p при наличии 4K/1440p.
- Проверен локальный запуск Lampa через `file://` с `Origin: null`: «Матрица» в Phantom воспроизводится в дубляже (13,86 с) и «Гоблин» (16,41 с), `readyState=4`, ошибок плеера и JavaScript нет. Тест выполнен в Chrome, не на физическом ТВ.

Этот патч устраняет подтверждённые ошибки клиента. Причина отказа Phantom на конкретном телевизоре ещё требует проверки по модели устройства, названию фильма и этапу сбоя; успешный запуск в Chrome не подтверждает совместимость с ТВ-плеером.

## Изменения 2.1.0

- Добавлены Phantom, VideoHUB и Kinotochka через HTTPS API Lumio. Удалён неработающий ZetflixDB; сохранённый выбор переводится на Zetflix.
- Исправлены относительные ссылки API, разбор ответа с видеоссылкой и передача качества, заголовков и субтитров в плеер, в том числе для следующей серии.
- Пустой ответ HTTP 200 больше не считается готовым HLS-видео. Перед запуском проверяются основной и вложенный плейлисты на прокси выбранного сервера. При ошибке проверяются ещё до двух вариантов качества той же озвучки. Если ни один не подошёл, плагин предлагает выбрать другую озвучку или источник.
- Запоздавшие ответы после смены экрана не запускают старое видео. Исправлен повторный запрос после RCH и обработка ошибки следующей серии.
- Для торрентов исправлены поисковые запросы по оригинальному и русскому названию, сериалам и году. Если настройки Jackett полностью пустые, подключается проверенный публичный парсер JacRed.su. Существующие адреса, ключи и настройки Prowlarr сохраняются.
- При открытии торрентов включается показ настроек парсера и TorrServer. Если TorrServer не указан, доступны переход к его настройкам и отдельный поиск раздач.

Проверка плейлистов не гарантирует доступность всех сегментов, кодеков или качества на конкретном устройстве. Для сторонних CDN проверка перед запуском пропускается, поскольку их транспорт и CORS могут отличаться от прокси API.

## Использование

1. Откройте карточку фильма или сериала → **Kas plugin** → выберите источник сверху или через боковой фильтр.
2. Выберите озвучку, сезон и серию. Если Phantom сообщает об отсутствии плейлиста, попробуйте другую озвучку или VideoHUB / Kinotochka.
3. В AniLiberty выберите релиз, затем серию. Если поиск пустой, попробуйте оригинальное название.

## Ограничения

- Lumio и WTCH — сторонние серверы. Их отказ или отключение источника нельзя исправить только клиентским JavaScript. Для Zetflix пока не найден публичный маршрут, который прошёл проверку загрузки видео.
- Filmix, Kodik и Rutube через WTCH используют HTTP. Браузерная Lampa по HTTPS может блокировать эти обращения как mixed content; поведение ТВ-приложений зависит от их сетевого транспорта.
- При нестабильности конкретной озвучки Phantom можно переключить озвучку вручную. Плагин не подменяет выбранный источник другим без участия пользователя.
- Собственный Lampac можно задать в настройках. Его список источников и требования авторизации определяет владелец сервера.
- Сохраняются таймлайны, отметки просмотра и настройки других расширений. Плагин не снимает ограничения источников и не меняет рекламные параметры ссылок AniLiberty.

## Изученные реализации

- [BwaRC](http://bwa.ad/rc): изучены подключения Kodik/VeoVeo, группировка озвучек и качеств; проверены публичные маршруты BWA. Плагин целиком не загружается и его ключи в Kas plugin не копируются.
- [Lampac: Kodik](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlineAnime/Kodik/Controller.cs), [Lampac: VeoVeo](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlineRUS/VeoVeo/Controller.cs): формат каталогов, сезонов, серий и видеоссылок.
- [Lumio](https://beta.mitsu.tv/plugins/lumio.js): публичный API, Phantom и формат получения видеопотоков. Удалённый плагин целиком не подключается.
- [Каталог плагинов на Pikabu](https://pikabu.ru/story/katalog_osnovnyikh_plaginov_dlya_lampa_12350672): использован для поиска альтернатив; каждое подключение проверялось отдельно.
- [Lampac: Zetflix](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlineRUS/Zetflix/Controller.cs): серверный разбор плееров и браузерный этап получения потоков.
- [NB557 online_mod](https://github.com/nb557/plugins/blob/main/online_mod.js), [вариант из каталога](http://llpp.in/v/vod.js), [Showy](http://showy.online/online.js), [Cinema](https://bylampa.github.io/cinema.js): проверены адреса и подходы к подключению источников.
- [PubTorr](https://lampame.github.io/main/pubtorr/pubtorr.js): список публичных парсеров; JacRed.su проверен сетевыми запросами.
- [Официальный Etor](http://cub.red/plugin/etor), [торренты Lampa](https://github.com/yumata/lampa-source/blob/main/src/components/full/start/torrents.js) и [API парсера](https://github.com/yumata/lampa-source/blob/main/src/core/api/sources/parser.js): штатные настройки и формат поиска.
- [WTCH](http://wtch.ch/online.js) и [документация AniLiberty API](https://aniliberty.top/api/docs/v1).

# Kas plugin 2.1 для Lampa

Онлайн-источники Filmix, Phantom, VideoHUB, Kinotochka, Rutube, VK Видео, AniLiberty / AniLibria и штатный поиск торрентов.

**Zetflix пока не восстановлен:** на проверенных публичных серверах он отключён либо возвращает ошибку. Пункт сохранён для повторной проверки и собственного Lampac, но эта версия не обещает его работоспособность. Подробности сетевых проверок ниже.

## Установка и обновление

В Lampa → Настройки → Расширения добавьте:

```text
https://menasco.github.io/lampa/kas_plugin.js
```

Если плагин уже установлен, обновите расширение и полностью перезапустите Lampa. Вторую копию добавлять не нужно. На кнопке должна быть версия **v2.1.0**.

Прежний стандартный адрес WTCH один раз заменяется на публичный API Lumio. При этом Filmix и Rutube продолжают использовать WTCH. Пользовательский адрес другого сервера сохраняется. Предыдущий адрес записывается в `ou_backend_previous`; изменить сервер можно в **Настройки → Kas plugin → Бэкенд источников**, затем перезапустить Lampa.

## Что исправлено

- Добавлены Phantom, VideoHUB и Kinotochka через HTTPS API Lumio. Удалён неработающий ZetflixDB; сохранённый выбор переводится на Zetflix.
- Исправлены относительные ссылки API, разбор ответа с видеоссылкой и передача качества, заголовков и субтитров в плеер, в том числе для следующей серии.
- Пустой ответ HTTP 200 больше не считается готовым HLS-видео. Перед запуском проверяются основной и вложенный плейлисты на прокси выбранного сервера. При ошибке проверяются ещё до двух вариантов качества той же озвучки. Если ни один не подошёл, плагин предлагает выбрать другую озвучку или источник.
- Запоздавшие ответы после смены экрана не запускают старое видео. Исправлен повторный запрос после RCH и обработка ошибки следующей серии.
- Для торрентов исправлены поисковые запросы по оригинальному и русскому названию, сериалам и году. Если настройки Jackett полностью пустые, подключается проверенный публичный парсер JacRed.su. Существующие адреса, ключи и настройки Prowlarr сохраняются.
- При открытии торрентов включается показ настроек парсера и TorrServer. Если TorrServer не указан, доступны переход к его настройкам и отдельный поиск раздач.

Проверка плейлистов не гарантирует доступность всех сегментов, кодеков или качества на конкретном устройстве. Для сторонних CDN проверка перед запуском пропускается, поскольку их транспорт и CORS могут отличаться от прокси API.

## Источники

| Источник | Подключение | Результат проверки 21.10.2026 |
|---|---|---|
| Filmix | WTCH, `/lite/fxapi` | Сохранено существующее подключение; видеопоток в этом обновлении повторно не проверялся |
| Phantom | Lumio, `/lite/phantom` | Получены видеоданные фильма и серии; отдельные озвучки возвращают пустые плейлисты |
| VideoHUB | Lumio, `/lite/cdnvideohub` | Получены основной и вложенный HLS-плейлисты и байты видеосегмента |
| Kinotochka | Lumio, `/lite/kinotochka` | Получен фрагмент MP4, HTTP 206 |
| Zetflix | Lumio, `/lite/zetflix` | Таймауты и HTTP 504; через WTCH — HTTP 403 `disable` |
| Rutube | WTCH, `/lite/rutubemovie` | Сохранено подключение; видеопоток в этом обновлении не проверялся |
| VK Видео | Lumio, `/lite/vkmovie` | Получены варианты видео; воспроизведение не подтверждено |
| AniLiberty / AniLibria | Напрямую, официальный API | Сохранена существующая интеграция; локальные тесты выбора и запуска серии проходят |
| Торренты | Штатный компонент Lampa, JacRed.su или ваш парсер | Получены раздачи для фильма и сериала; для воспроизведения нужен доступный TorrServer |

VeoVeo проверен, но не добавлен в стандартное меню: основной плейлист доступен, вложенный возвращает HTTP 401. На собственном сервере поддерживаются также VeoVeo, HDVB и Vibix, если он объявляет их доступными.

## Использование

1. Откройте карточку фильма или сериала → **Kas plugin** → выберите источник сверху.
2. Выберите озвучку, сезон и серию. Если Phantom сообщает об отсутствии плейлиста, попробуйте другую озвучку или VideoHUB / Kinotochka.
3. В AniLiberty выберите релиз, затем серию. Если поиск пустой, попробуйте оригинальное название.
4. Для торрентов укажите свой рабочий **TorrServer** в настройках Lampa. Плагин настраивает поиск при пустой конфигурации, но не устанавливает TorrServer и не предоставляет общий сервер для просмотра. Поиск без TorrServer можно открыть отдельной кнопкой.

Node.js 18+:

```sh
npm ci
npm test
```

Тесты проверяют миграцию настроек, разбор настоящего HTML-формата через jsdom, выбор сезона и озвучки, передачу потока в Lampa.Player, следующие серии, заголовки, субтитры, относительные ссылки, ошибки и отмену запросов, резервное качество и настройку торрентов.

## Ограничения

- Lumio и WTCH — сторонние серверы. Их отказ или отключение источника нельзя исправить только клиентским JavaScript. Для Zetflix пока не найден публичный маршрут, который прошёл проверку загрузки видео.
- Filmix и Rutube через WTCH используют HTTP. Браузерная Lampa по HTTPS может блокировать эти обращения как mixed content; поведение ТВ-приложений зависит от их сетевого транспорта.
- При нестабильности конкретной озвучки Phantom можно переключить озвучку вручную. Плагин не подменяет выбранный источник другим без участия пользователя.
- Собственный Lampac можно задать в настройках. Его список источников и требования авторизации определяет владелец сервера.
- Сохраняются таймлайны, отметки просмотра и настройки других расширений. Плагин не снимает ограничения источников и не меняет рекламные параметры ссылок AniLiberty.

## Изученные реализации

- [Lumio](https://beta.mitsu.tv/plugins/lumio.js): публичный API, Phantom и формат получения видеопотоков. Удалённый плагин целиком не подключается.

- [Lampac: Zetflix](https://github.com/lampac-nextgen/lampac/blob/main/Modules/OnlineRUS/Zetflix/Controller.cs): серверный разбор плееров и браузерный этап получения потоков.
- [NB557 online_mod](https://github.com/nb557/plugins/blob/main/online_mod.js), [вариант из каталога](http://llpp.in/v/vod.js), [Showy](http://showy.online/online.js), [Cinema](https://bylampa.github.io/cinema.js): проверены адреса и подходы к подключению источников.

- [Официальный Etor](http://cub.red/plugin/etor), [торренты Lampa](https://github.com/yumata/lampa-source/blob/main/src/components/full/start/torrents.js) и [API парсера](https://github.com/yumata/lampa-source/blob/main/src/core/api/sources/parser.js): штатные настройки и формат поиска.
- [WTCH](http://wtch.ch/online.js) и [документация AniLiberty API](https://aniliberty.top/api/docs/v1).
